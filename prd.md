## 3. Análisis del Sitio de Referencia (pureclean.cl)

### 3.1 Estructura de Páginas / Secciones
1. **Barra superior (Top bar):** Teléfono de ventas + email
2. **Navbar:** Logo | Servicios (dropdown) | Contacto | Nuestra Historia | CTA Button "Cotiza tu servicio"
3. **Hero Section:** Tagline principal + subtítulo + CTA "Cotiza ahora"
4. **Sección Diferenciadores:** 4 pilares (Tecnología / Seguridad / Experiencia / Cultura organizacional)
5. **Propuesta de Valor:** Párrafo narrativo centrado
6. **Sección Equipo:** Fotos o videos del equipo con descripción humanizada
7. **Servicios:** Grid de tarjetas con imagen, título y enlace a subpágina
8. **Logos de Clientes:** Carrusel o grid con logos de empresas cliente
9. **Formulario de Contacto:** Sección con título + formulario (nombre, empresa, email, teléfono, mensaje)
10. **Footer:** Logo | Menú de acceso rápido | Ubicación | Teléfono | Email | Copyright

### 3.2 Estilo Visual

| Elemento | Especificación |
|---|---|
| **Paleta de colores** | Azul marino oscuro `#1B2A4A` (principal) + Teal/verde-azul `#3AAFA9` (acento) + Blanco `#FFFFFF` (fondos) + Gris claro `#F4F6F9` (fondos alternativos) |
| **Tipografía** | Sans-serif moderna y limpia (e.g. Inter, Poppins o similar). Títulos bold. Cuerpo regular. |
| **Logo FyS** | Usar el logo existente: círculo azul marino con "F&S" en teal, con estrellas destellantes. Fondo blanco o transparente. |
| **Estética general** | Profesional, limpio, corporativo pero accesible. Mucho espacio en blanco. Fotografías reales de trabajo industrial/limpieza. |
| **Botones CTA** | Fondo teal `#3AAFA9`, texto blanco, bordes redondeados suaves |
| **Cards de servicios** | Imagen superior + título + breve descripción + link. Sombra suave. Hover con elevación. |
| **Navbar** | Fondo blanco con sombra suave. Sticky al hacer scroll. |

### 3.3 Tono y Voz
- Profesional pero cercano
- Lenguaje en español chileno formal
- Énfasis en confianza, familia, compromiso y resultados
- Frases directas y de acción ("Transformamos tu espacio", "Cotiza ahora")

## 5. Requerimientos Técnicos

| Ítem | Especificación |
|---|---|
| **Stack sugerido** | HTML5 + CSS3 + JavaScript vanilla (o React si el agente lo prefiere) |
| **Responsivo** | Sí — Mobile First. Breakpoints: 320px / 768px / 1200px |
| **Navbar sticky** | Sí, se fija al inicio del scroll |
| **Animaciones** | Fade-in suave en secciones al hacer scroll (Intersection Observer o AOS.js) |
| **Formulario** | Funcional con validación básica de campos. Integrar Formspree o mailto |
| **Fuentes** | Google Fonts: `Poppins` (títulos, bold 700) + `Inter` (cuerpo, regular 400) |
| **Íconos** | Font Awesome 6 o Lucide Icons |
| **Imágenes** | Usar URLs de Unsplash (sin descarga): foto industrial, oficinas limpias, pisos, vidrios |
| **Logo** | Usar el archivo provisto: `ChatGPT_Image_5_ene_2026__04_51_21_p_m_.png` |
| **SEO básico** | Meta title, meta description, Open Graph tags |
| **Performance** | Lazy loading en imágenes. Sin dependencias pesadas innecesarias. |
